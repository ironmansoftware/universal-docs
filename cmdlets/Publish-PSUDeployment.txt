
NAME
    Publish-PSUDeployment
    
SYNOPSIS
    Creates a deployment to a PowerShell Universal server.
    
    
SYNTAX
    Publish-PSUDeployment [-AppToken <String>] [-ComputerName <String>] [-Credential <PSCredential>] [-Integrated] -Name <String> [-Synchronous] [-TrustCertificate] [-UseDefaultCredentials] -Version <String> [<CommonParameters>]
    
    
DESCRIPTION
    Creates a deployment to a PowerShell Universal server.
    

PARAMETERS
    -AppToken <String>
        The AppToken that is used for calling the PowerShell Universal Management API. You can also call Connect-PSUServer before calling this cmdlet to set the AppToken for the entire session.
        
        Required?                    false
        Position?                    named
        Default value                None
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false
        
    -ComputerName <String>
        The HTTP address of the PSU Management API.
        
        Required?                    false
        Position?                    named
        Default value                None
        Accept pipeline input?       False
        Aliases                      Uri
        Accept wildcard characters?  false
        
    -Credential <PSCredential>
        The credentials used to connect to the PowerShell Universal server. This is only used if the server is not using default credentials.
        
        Required?                    false
        Position?                    named
        Default value                None
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false
        
    -Integrated [<SwitchParameter>]
        Whether to use integrated mode for this cmdlet.
        
        Required?                    false
        Position?                    named
        Default value                False
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false
        
    -Name <String>
        The name of the deployment.
        
        Required?                    true
        Position?                    named
        Default value                None
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false
        
    -Synchronous [<SwitchParameter>]
        Whether to wait for the deployment to complete before returning.
        
        Required?                    false
        Position?                    named
        Default value                False
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false

        Required?                    false

        Default value                False
        Accept pipeline input?       False
        Aliases                      none
        Accept wildcard characters?  false
        
    -Version <String>
        The version of the deployment.
        
        Required?                    true
