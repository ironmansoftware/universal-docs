
NAME
    New-PSUGitSetting
    
SYNOPSIS
    Creates a new git setting for a PowerShell Universal application. This setting is used to configure the git repository for the application.
    
    
SYNTAX
    New-PSUGitSetting [-AppToken <String>] [-Branch <String>] [-ComputerName <String>] [-Credential <PSCredential>] [-ExternalGit] [-GitCredential <PSCredential>] [-Integrated] [-Interval <Int32>] [-Mode {Manual | Automatic}] [-ProxyUrl <String>] [-Remote <String>] [-SyncBehavior {TwoWay | OneWay | PushOnly}] [-TrustCertificate] [-UseDefaultCredentials] [<CommonParameters>]
    
    
DESCRIPTION
    Creates a new git setting for a PowerShell Universal application. This setting is used to configure the git repository for the application.

NOTES
    
    
        
    
    -------------------------- Example 1 --------------------------
    
    PS C:\> New-PSUGitSetting -Branch 'main' -Name 'MyApp'
    
    Creates a local git setting for the application named 'MyApp' with the branch set to 'main'.
    -------------------------- Example 2 --------------------------
    
    PS C:\> New-PSUGitSetting -Remote 'https://www.example.com/repo.git' -Branch 'main' -Name 'MyApp'
    
    Creates a remote git setting for the application named 'MyApp' with the branch set to 'main' and the remote repository set to 'https://www.example.com/repo.git'.
